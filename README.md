# AutoDock & Pack — Reference Docs

Working documents for HandsOffLabs' AutoDock & Pack autonomous checkout kiosk (2nd prototype), reconciling the Edge-AI Checkout Kiosk Blueprint and the pre-seed investor deck.

## Contents

- [`docs/system-explainer.html`](docs/system-explainer.html) — why RK3588S, the recognition model plan (fast path / deep path), SKU onboarding, instant deployment, multi-branch fleet management, cloud sync, daily-usage analytics, and discounts/free items.
- [`docs/build-roadmap.html`](docs/build-roadmap.html) — step-by-step plan from the Mac M4 software prototype, through a real-RK3588-hardware validation gate, to the production device model and the Bengaluru pilot.
- [`docs/training-pipeline.html`](docs/training-pipeline.html) — how to train the recognition model on Indian groceries: difficulty tiers (packaged goods / rice-dal-masala varieties & grades / produce), data collection, metric-learning training method, evaluation targets, and the post-launch improvement loop.

Each file is self-contained — open it directly in a browser to view.

## Status

Living documents — update as the architecture, BOM, and pilot results firm up.
